# AI development instructions

## Start here

Read [README.md](README.md) and [ENGINEERING.md](ENGINEERING.md), then inspect applicable project documentation, current branch, open work and existing tests before editing.

## Working rules

- Preserve existing architecture, interfaces, data and project-specific constraints.
- Work on the appropriate development branch; do not overwrite unrelated work or rewrite history.
- Implement real functionality, not placeholders presented as complete.
- Keep changes focused and use existing conventions. Do not move files without checking all references and build/deployment dependencies.
- Never expose secrets or private data. Use test fixtures and non-production environments.
- Run applicable tests and build checks; report actual results and clearly identify unverified work.
- Update relevant documentation and include acceptance criteria, risks and rollback notes in pull requests.
- Existing project-specific guidance and more specific scoped instructions take precedence over this baseline.
